## 三、本次修复：分类页价格为 0.00 / 已售无数值

### 现象

```text
https://www.yjxj.cn/list/?cat=17
```

- 商品卡片价格显示 `0.00`
- 销量只显示“已售”，后面没有数字

### 根因

原版 Java `ProductListResDTO` 同时返回：

```json
{
  "productPrice": "70.00",
  "price": "70.00",
  "virtualSales": 1
}
```

前端商品卡读取的是：

```text
product.price
product.virtualSales
```

Rust `ProductVO` 只返回：

```json
{
  "productPrice": "70.00",
  "sales": 1
}
```

所以：

- `product.price` → `undefined` → `FormatPrice` 显示 `0.00`
- `product.virtualSales` → `undefined` → 只显示“已售”

### 修复位置

```text
rust/crates/api/public/src/routes/catalog/search_admin.rs
```

`POST /api/search/search/getProduct` 现在会给每条记录补齐：

```text
price            = productPrice
orgProductPrice  = productPrice
virtualSales     = sales
productSku       = []
deliveryMode     = 1
```

### 构建后预期

```text
/list/?cat=17
价格：70.00
已售：1
```

### 2. 下载并校验

```bash
curl -fL -o rustshop \
  https://github.com/lanline123/rustshop/releases/download/build-<N>/rustshop

curl -fL -o rustshop.sha256 \
  https://github.com/lanline123/rustshop/releases/download/build-<N>/rustshop.sha256

sha256sum -c rustshop.sha256
```

### 3. 部署

```bash
cd /www/wwwroot/tigshop-rust

cp -a tigshop tigshop.bak.before_build<N>
mv rustshop tigshop
chown root:root tigshop
chmod 755 tigshop

systemctl restart tigshop
sleep 2

systemctl is-active tigshop
curl -s http://127.0.0.1:8080/adminapi/health
```

### 4. 回滚

