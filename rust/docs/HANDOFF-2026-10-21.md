## 三、本次修复：分类页价格为 0.00 / 已售无数值

### 现象

```text
https://www.yjxj.cn/list/?cat=17
```

- 商品卡片价格显示 `0.00`
- 销量只显示“已售”，后面没有数字

### 根因

原版 Java `ProductListResDTO` 同时返回：

```json
{
  "productPrice": "70.00",
  "price": "70.00",
  "virtualSales": 1
}
```

前端商品卡读取的是：

```text
product.price
product.virtualSales
```

Rust `ProductVO` 只返回：

```json
{
  "productPrice": "70.00",
  "sales": 1
}
```

所以：

- `product.price` → `undefined` → `FormatPrice` 显示 `0.00`
- `product.virtualSales` → `undefined` → 只显示“已售”

### 修复位置

```text
rust/crates/api/public/src/routes/catalog/search_admin.rs
```

`POST /api/search/search/getProduct` 现在会给每条记录补齐：

```text
price            = productPrice
orgProductPrice  = productPrice
virtualSales     = sales
productSku       = []
deliveryMode     = 1
```

### 构建后预期

```text
/list/?cat=17
价格：70.00
已售：1
```

  https://github.com/lanline123/rustshop/releases/download/build-<N>/rustshop.sha256

```bash

sleep 2

systemctl is-active tigshop
curl -s http://127.0.0.1:8080/adminapi/health
```

## 七、本轮已完成的兼容修复

### 7.1 第一轮（`build-18` 已部署）

| 问题 | 修复 |
|---|---|
| `INT UNSIGNED` 解码失败 | `rust/数据库兼容修正.sql` |
| `JSON` 解码失败 | 同上，转 `TEXT` |
| `DATE` 解码失败 | 同上，转 `VARCHAR(10)` |
| `Authorization: Bearer null` 导致 401 | 42 个 public optional auth 把非法 token 当游客 |
| 分类页 `cat:"17"` 字符串 400 | 搜索 DTO 数字字段兼容字符串 |
| 业务错误 HTTP 400 | 恢复 Java 语义：业务错误 HTTP 200 + code/msg |
| 统计页 400/无数据 | 补齐 `salesData` / `salesStatisticsData` / 平铺指标 |
| 订单详情 `shop/detail` 400 | 订单详情平铺 + `shopId` |
| 物流公司列表 `length` 崩溃 | 返回 `records` + `logisticsId/logisticsName` |
| 首页 `toString` 崩溃 | 补齐 panel 实时/控制台字段 |
| 分类页价格 0.00 / 销量空 | 搜索接口补 `price` / `virtualSales` |
