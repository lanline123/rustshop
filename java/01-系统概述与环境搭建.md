## 1. TigShop 简介

### 1.1 产品定位
TigShop 是一套功能完善的开源 B2B2C 多商户电商平台系统，支持多种前端部署方式及双后端架构（JAVA/PHP），为企业级电商项目提供完整的解决方案。

**核心特性:**
- ✅ **多端覆盖**: PC 端、移动端 (H5)、小程序、iOS/Android APP、管理后台全覆盖
- ✅ **双后端架构**: 同时支持 JAVA Spring Boot 和 PHP ThinkPHP/Laravel 两种后端技术栈
- ✅ **SaaS 化部署**: 支持多租户独立部署，灵活的扩展架构
- ✅ **丰富营销**: 内置优惠券、拼团、秒杀、积分、礼品卡等完整营销体系
- ✅ **分销系统**: 完善的多级分销机制，佣金自动结算
- ✅ **装修系统**: 可视化拖拽式页面搭建，零代码快速建站
- ✅ **微信生态**: 深度集成微信支付、公众号、小程序、视频号直播

### 1.2 应用场景
- 🏪 B2B2C 多商户电商平台
- 🛒 品牌自营商城
- 📱 社交电商（分销 + 拼团）
- 🎁 内容电商（直播带货 + 买家秀）
- 🌍 跨境电商（多支付集成：PayPal/Stripe/支付宝等）

## 6. Node.js 安装配置

### 6.1 下载安装

#### Windows 系统
1. 访问 Node.js 官网：https://nodejs.org/
2. 下载 LTS 版本（推荐 16.x 或 18.x）
3. 运行安装包，按向导完成安装
4. 安装完成后打开命令提示符，输入 `node -v` 验证安装

#### macOS 系统
```bash
# 使用 Homebrew 安装
brew install node@16

# 或直接下载 dmg 安装包
curl https://nodejs.org/dist/v16.18.0/node-v16.18.0-darwin-x64.tar.gz | tar -xz -C /usr/local
```

#### Linux 系统 (Ubuntu/Debian)
```bash
# 安装 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -

# 安装 Node.js
sudo apt-get install -y nodejs

# 验证安装
node -v
npm -v
```

### 6.2 验证安装

```bash
# 检查 Node.js 版本
node -v

# 检查 npm 版本
npm -v

# 检查 yarn 版本（可选）
yarn -v
```

为了加速依赖下载，建议配置国内镜像源：

### 7.5 常见配置问题

#### 问题 1: 端口被占用
**解决方案**: 修改 vite.config.ts 中的 port 配置
```javascript
server: {
  port: 3001  // 改为其他端口
}
```

#### 问题 2: 代理不生效
**解决方案**: 确保请求 URL 正确配置
- 开发环境：使用 `/adminapi` 或 `/api` 前缀
- 生产环境：根据实际部署调整

#### 问题 3: TypeScript 类型报错
**解决方案**: 
```bash
# 重新生成类型定义
npm run build

# 或者删除 node_modules/.vite 目录后重新构建
rm -rf node_modules/.vite && npm run build
```

## 8. 常见问题解决

### 8.1 Node.js 安装问题

**问题**: 安装后无法识别 `node` 或 `npm` 命令  
**解决**: 
```bash
# Windows: 检查环境变量是否包含 Node.js 路径
# 通常默认路径：C:\Program Files\nodejs

# macOS/Linux: 检查 PATH 变量
echo $PATH

# 手动添加（临时）
export PATH=$PATH:/usr/local/bin

# 永久添加（添加到 ~/.bashrc 或 ~/.zshrc）
echo 'export PATH=$PATH:/usr/local/bin' >> ~/.bashrc
source ~/.bashrc
```

### 8.2 npm 下载速度慢

**解决方案**:
```bash
# 1. 配置淘宝镜像
npm config set registry https://registry.npmmirror.com

# 2. 使用 cnpm 替代（已配置淘宝镜像的全局包管理器）
npm install -g cnpm --registry=https://registry.npmmirror.com

# 3. 或使用 yarn
npm install -g yarn
yarn config set registry 'https://registry.npmmirror.com'
```

### 8.3 Vue3 项目构建失败

**常见原因**: 依赖版本冲突  
**解决方案**:
```bash
# 1. 清理缓存
npm cache clean --force

# 2. 删除 node_modules 和锁文件
rm -rf node_modules package-lock.json

# 3. 重新安装
npm install

# 4. 如果还不行，尝试删除所有 node_modules 后全局更新
npm update -g
```

### 8.4 Vite 代理配置无效

**解决方案**:
1. 确保请求使用相对路径（如 `/adminapi/user/list`）
2. 检查代理配置的目标地址是否正确
3. 确认 `changeOrigin: true` 已设置
4. 清除浏览器缓存后重试

### 8.5 后端连接失败

**排查步骤**:
1. 确认后端服务已启动
2. 检查 CORS 配置（跨域问题）
3. 验证 API 基础地址配置
4. 查看浏览器控制台 Network 面板的详细错误

### 8.6 IDE 配置建议

**IntelliJ IDEA (JAVA 开发)**:
- 安装 Lombok 插件
- 配置 Maven 镜像仓库（建议使用阿里云）

- 配置自动保存和格式化

- 设置代码审查规则（PSR-12）
