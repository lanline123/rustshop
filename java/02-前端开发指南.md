## 1. PC 端开发

### 1.1 项目概述

TigShop PC 端采用 Vue3 + Vite 构建，支持 CSR（客户端渲染）和 SSR（服务端渲染）两种模式，提供完整的电商购物体验。

**技术栈:**
- 框架：Vue 3.x (Composition API)
- 构建工具：Vite 4.x
- 状态管理：Pinia
- UI 组件库：Element Plus
- 路由管理器：Vue Router 4
- HTTP 请求：Axios
- TypeScript: 类型安全支持

#### store/modules/user.ts - 用户状态管理
```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import * as api from '@/api'

export const useUserStore = defineStore('user', () => {
  // 状态
  const token = ref(localStorage.getItem('token') || '')
  const userInfo = ref<any>(null)
  
  // 计算属性
  const isLoggedIn = computed(() => !!token.value)
  const userId = computed(() => userInfo.value?.userId || null)
  
  // 方法
  async function login(loginForm: any) {
    const result = await api.user.login(loginForm)
    token.value = result.token
    localStorage.setItem('token', result.token)
    await getUserInfo()
  }
  
  async function getUserInfo() {
    const result = await api.user.getInfo()
    userInfo.value = result
  }
  
  function logout() {
    token.value = ''
    userInfo.value = null
    localStorage.removeItem('token')
  }
  
  return {
    token,
    userInfo,
    isLoggedIn,
    userId,
    login,
    getUserInfo,
    logout
  }
})
```

#### utils/request.ts - Axios 请求封装
```typescript
import axios from 'axios'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/store/modules/user'

const instance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 15000
})

// 请求拦截器
instance.interceptors.request.use(
  config => {
    const userStore = useUserStore()
    if (userStore.token) {
      config.headers['Authorization'] = `Bearer ${userStore.token}`
    }
    return config
  },
  error => {
    console.error('Request error:', error)
    return Promise.reject(error)
  }
)

// 响应拦截器
instance.interceptors.response.use(
  response => {
    const res = response.data
    // 根据业务逻辑判断错误码
    if (res.code !== 200) {
      ElMessage.error(res.msg || '请求失败')
      return Promise.reject(new Error(res.msg || 'Error'))
    }
    return res
  },
  error => {
    console.error('Response error:', error)
    let message = error.message
    
    if (error.response) {
      switch (error.response.status) {
        case 401:
          message = '未授权，请重新登录'
          break
        case 403:
          message = '拒绝访问'
          break
        case 404:
          message = '请求地址不存在'
          break
        case 500:
          message = '服务器内部错误'
          break
      }
    }
    
    ElMessage.error(message)
    return Promise.reject(error)
  }
)

export default instance
```

### 1.5 CSR vs SSR 模式

#### CSR (Client-Side Rendering) - 客户端渲染

**适用场景**: 
- 后台管理系统
- 交互复杂的页面
- SEO 要求不高的页面

**特点**:
- 首屏加载较慢，但交互流畅
- 对搜索引擎友好度较低
- 适合动态内容为主的页面

**配置方式**:
```javascript
// vite.config.ts
export default defineConfig({
  // CSR 模式默认就是这种配置
  ssr: false
})
```

#### SSR (Server-Side Rendering) - 服务端渲染

**适用场景**:
- 商城首页、商品列表等需要 SEO 的页面
- 对首屏速度要求高的场景

**特点**:
- 首屏加载快，SEO 友好
- 需要 Node.js 服务端支持
- 增加了服务端压力

**配置方式**:
```typescript
// vite.config.ts (SSR 模式)
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import fs from 'fs'
import path from 'path'

export default defineConfig({
  plugins: [vue()],
  ssr: {
    // 需要排除不兼容的包
    noExternal: []
  },
  build: {
    rollupOptions: {
      input: {
        index: path.resolve(__dirname, 'index.html')
      }
    }
  }
})
```

**Nuxt.js 方案** (更成熟的 SSR 框架):
```bash
# 安装 Nuxt 3
npx nuxi@latest init tigshop-ssr

cd tigshop-ssr
npm install
```

- 微信小程序

- 百度小程序

- iOS APP
- Android APP

## 4. 开发规范总结

### 4.1 代码风格

#### TypeScript 最佳实践
```typescript
// ✅ 推荐使用
interface UserInfo {
  id: number
  name: string
  email?: string
}

async function fetchUser(id: number): Promise<UserInfo> {
  // implementation
}

// ❌ 避免使用
const user: any = {}
```

#### 组件设计原则
1. **单一职责**: 每个组件只负责一个功能
2. **props 精简**: 尽量减少 props 数量
3. **事件命名**: 使用驼峰命名，如 `onSubmit`、`onClick`
4. **插槽设计**: 合理使用默认插槽和作用域插槽

### 4.2 命名规范汇总

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| 组件名 | PascalCase | `UserProfile.vue` |
| 文件名 | kebab-case | `user-profile.vue` |
| 组件 prop | camelCase | `userId`, `showModal` |
| 事件名 | onXxx | `onClick`, `onSubmit` |
| 变量/函数 | camelCase | `userName`, `getUserInfo` |
| 常量 | UPPER_SNAKE_CASE | `API_BASE_URL` |
| CSS 类 | kebab-case | `.user-profile` |
| 文件夹 | kebab-case | `user-management/` |

// utils/ throttle.ts
export function debounce<T extends (...args: any[]) => any>(
  func: T,
  wait: number
): (...args: Parameters<T>) => void {
  let timeout: ReturnType<typeof setTimeout> | null = null
  
  return function executed(...args: Parameters<T>) {
    if (timeout) clearTimeout(timeout)
    timeout = setTimeout(() => func.apply(this, args), wait)
  }
}

### 5.2 常见 Bug 排查

#### 问题 1: 热更新失效
**原因**: Vite 缓存问题  
**解决**:
```bash
# 删除缓存
rm -rf node_modules/.vite

# 重启开发服务器
npm run dev
```

#### 问题 2: 跨域问题
**原因**: CORS 配置不当  
**解决**:
```typescript
// vite.config.ts
server: {
  proxy: {
    '/api': {
      target: 'http://backend:8080',
      changeOrigin: true,
      rewrite: path => path.replace(/^\/api/, '')
    }
  }
}
```

#### 问题 3: 生产环境 404
**原因**: SPA 路由配置问题  
**解决**: 配置服务器重写规则
```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```
